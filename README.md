# ALU and Shifting Operations
This project implements an 8-bit ALU (Arithmetic Logic Unit) using Logisim.

** Features:
- Arithmetic operations
- Logic operations
- Shift operations
- Multiplexer-based operation selection
- Status flags support:
  - Carry (C)
  - Overflow (V)
  - Negative (N)
  - Zero (Z)

** Operations Included:
- Addition
- Subtraction
- Increment / Decrement
- AND
- OR
- XOR
- NOR
- NOT
- Shift Left
- Shift Right

** Purpose:
The project demonstrates the design and implementation of a digital ALU circuit using combinational logic components in Logisim.
